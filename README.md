# ETZ_9_class_2026

Рабочие материалы по ЕТЗ 2026–27 (СОУШ, робототехника), региональный заключительный этап, 9 класс.

## Задача (со слов автора проекта, краткая версия ЕТЗ с robot.mipt.ru)

- Устройство переносит шашки по операционному полю 9×6 клеток.
- Материалы сдаются через личный кабинет до регионального этапа.
- Питание только от аккумулятора, до 4S.
- Три шаговых мотора, каждый потребляет до 2 А в пике.

## Закупленное и используемое железо

- Шаговые моторы с драйверами A4988
- Raspberry Pi
- Аккумуляторы 18650: LiitoKala HG2, 3000 мАч
- Электромагнит YDJK P25/20 для захвата шашек

Подробности по каждому узлу, расчёты и схемы — в папке `docs/`. Список закупок — в `purchases.csv`.

## Как читать пометки о проверке

В технических файлах рядом с числами (напряжение, ток, сечение провода, распиновка) ставятся пометки:

- **[проверено]** — сверено с даташитом или документацией производителя, указан источник.
- **[не проверено]** — взято из описания товара, памяти или чата, требует сверки.

Если данные в схеме и в списке закупок расходятся, это записывается в `decisions.md` отдельной строкой.
